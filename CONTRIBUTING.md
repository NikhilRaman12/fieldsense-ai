# Contributing to FieldSense AI

Thank you for your interest in helping people step outside, connect with living nature, and record empirical observations.

## Core Philosophical Guidelines
1. **Nature Comes First**: Features should encourage looking away from the screen, not pulling the user into an endless feed.
2. **Honesty & Transparency**: Never fabricate observations, test metrics, scientific certainty, or AI origins.
3. **Privacy**: Always keep observations and photos local by default.

## Development Setup
1. Clone the repository and install dependencies:
   ```bash
   npm install
   ```
2. Run test suites:
   ```bash
   npm test
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

## Good First Issue Ideas
- **Audio Soundscape Prompts**: Expand acoustic prompts for the *Bird & Habitat Observer* template.
- **Micro-Climate Field Guides**: Add seasonal guides for observing soil moisture layers and fungal mycelium.
- **Export Formats**: Add GeoJSON or CSV export options alongside the existing validated JSON export.
